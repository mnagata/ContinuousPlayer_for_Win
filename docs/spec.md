# ContinuousPlayer Windows版仕様

参照元: `ContinuousPlayer_for_Android/docs/spec.md`、同リポジトリの`app/src/main/java/jp/nagu/continuousplayer`と`app/src/main/res`。参照文書は移植元の仕様として扱い、Windows固有の実装を以下に定義する。

## 構成

| 対象 | 実装 |
|---|---|
| UI | WinUI 3 / Windows App SDK 2.5.1 / CommunityToolkit.Mvvm |
| ターゲット | .NET 10、Windows SDK 26100、最低OS 17763 |
| アーキテクチャ | x64 / ARM64（検証対象はx64） |
| 配布形態 | 単一プロジェクトMSIX、WinApp CLIによる開発登録 |

## 画面と操作

ホームはAndroid版の濃紺グラデーション、重なる映像フレームと再生矢印のロゴ、英字ラベル、アプリ名、280×56の選択ボタンとExitを再現する。小さいウィンドウではスクロールする。初期サイズは1000×740 DIP、最小440×380 DIPを目安にモニターのDPIで調整する。

ブラウザーは最大880×800 DIP。同一のオーバーレイを維持し、戻る・キャンセル・フォルダー名・再読み込みを上部に配置する。ファイル行は20 DIPの名前と再生アイコン、フォルダー行には右矢印を表示する。NASのサーバー一覧にはアドレスを表示する。リストはListViewで仮想化する。ブラウザー外のクリックでは閉じない。

ファイル選択後は黒い再生画面を描画してからブラウザーを閉じる。再生時は全画面。一時停止時のみホーム・ファイル名・再開・情報・フォルダー・終了を上部に表示する。矢印キーは一時停止中も←／→で前／次のファイル、↑／↓で10秒巻き戻し／早送りに使用し、ツールバー内のボタン間はTab／Shift+Tabで移動する。縦長ウィンドウでは再生情報を下部に表示する。音声のみの場合は中央にファイル名を表示する。F11でウィンドウ表示に戻せる。

タッチは左右1/3のタップで±10秒、中央1/3で再生切り替え。100 DIP以上かつ100 DIP/秒以上の横スワイプで前後移動する。タップはポインターの各解放を処理するため、ダブルタップは同じ操作を2回行う。複数ポインターは最初の1本を対象にする。キーボードとメディアキーはREADMEの操作表のとおり。

操作ボタンは48 DIPを基本とし、AutomationId・読み上げ名・フォーカス表示を付ける。色はテーマ資源にまとめ、HighContrastではシステム色を使用する。

動画が実際に再生中でウィンドウがアクティブな間、マウスの移動・クリックから3秒でカーソルを非表示にする。移動・クリック・画面への再進入で再表示し、待ち時間をリセットする。一時停止、バッファリング、音声のみの再生、ダイアログ、再生終了・画面遷移・ウィンドウ非アクティブ時には表示へ戻す。カーソル変更はページ内に限定し、プレイヤー終了時にタイマーを停止、ウィンドウ終了時にカーソル資源を解放する。

非表示には透明なInputCursorを使用し、入力用コントロールとContentIslandに設定する。実際のポインター座標を監視して待ち時間を管理する。キーボード再開後にシステム矢印が残る場合に備え、非表示への切り替え時に元の座標へ戻るポインター更新を送る。非アクティブ時、マウスボタン操作中、OSがポインターを非表示にしている場合は更新を送らない。

## フォルダーと再生

- ローカル・USBは標準フォルダーピッカーまたはドライブ一覧から追加する。追加画面の「このフォルダを使用」で保存済み一覧に戻る。登録だけでは再生しない。
- 読み取りは選択フォルダーの直下のみ。再帰スキャンは行わない。ローカルファイルを変更・削除しない。
- 対応拡張子、AppleDoubleの除外、OP/EDのグループ内位置だけの並べ替え、季節シリーズの並べ替えはAndroid版のロジックをC#へ移植する。
- 選択インデックスから0秒で開始。末尾で停止し、自動リピートしない。前後移動は範囲内だけ行う。一時停止中の曲送りは停止状態を保持する。
- 巻き戻しは0秒で止める。既知の末尾を超える早送りは次があれば曲送り、なければ移動しない。CanSeekがfalseのソースはシークしない。
- 再生エラーは自動スキップせず、ファイル名・エラー・HRESULTと再試行／別ファイル／キャンセルを表示する。
- 再生画面を離れるとMediaPlayer・MediaSource・画面消灯抑止を解放する。ウィンドウが非アクティブになると一時停止し、自動再開しない。
- Escapeとフォルダーボタンは停止して現在の再生元を開き、ファイルIDで選択位置を復元する。ホームは再生を停止して初期画面へ戻る。
- 再生情報にファイル名・サイズ・時間・取得できた映像／音声のエンコード属性・Windowsの音声出力設定を表示する。既定出力の実際の物理デバイス名が取得できないときは「Windows既定の再生デバイス」と表示する。

## 保存

登録済みフォルダー、最後の登録先、再生元の階層、ファイルIDをJSONで保存する。同じキーの再登録は更新する。DLNAのキーはサーバーIDとフォルダーID、ローカルは大文字小文字を無視した絶対パス。ファイルへの書き込みを直列化し、一時ファイルから置き換える。壊れた保存データは起動時に案内し、登録の再作成が可能。再生位置・プレイリスト・実行中のブラウザー位置は復元しない。

保存済み一覧の登録解除はDelete・右クリック・長押し・ボタンから確認ダイアログを開いて行う。サーバーやドライブがオフラインでも解除できる。実ファイルは削除しない。

## DLNA

- SSDP M-SEARCHはIPv4マルチキャスト239.255.255.250:1900、4秒間、1.5秒間隔、最大32 LOCATION。デバイス記述はその後に順次取得する。UDNで重複を除く。
- ContentDirectoryのルートは0。SOAP BrowseDirectChildrenを200件単位で取得する。次ページはフィルター後の件数でなくNumberReturnedで進める。
- DIDL-Liteのcontainerとaudio/video HTTPリソースを扱う。汎用MIMEは拡張子で判定する。元データを変換済みリソースより優先する。
- 同じ項目の繰り返し、不完全なページ、10万件を超える一覧はエラー。XMLは4 MiBまで、DTDと外部エンティティは禁止。接続5秒、要求・読み取り8秒の上限を設定する。
- 登録時にサーバーID・名称とフォルダーのID階層を保存し、URLは永続化しない。登録先を開くとサーバーを再探索する。UDNのないサーバーではLOCATIONをIDに使うため、IP変更に追従できない場合がある。
- 通信中は前の一覧と見出しを維持し、古い選択・戻る・登録・再読み込みを無効にする。キャンセルは常時可能。DLNAのみ0.5秒後にローディング表示を重ねる。エラーでも登録は保持する。
- Windowsファイアウォールやネットワークのマルチキャスト設定に依存する。Synologyなど実機NASの探索・再生・シーク・切断は別途検証する。

## Android版との差分・未対応

AndroidのSAF・TV用権限・画面回転・メディアセッションはWindowsのピッカー・ドライブ・ウィンドウリサイズ・SMTCに置換する。Windowsの標準コーデックで再生するためExoPlayerとの完全な形式互換性は保証しない。

USBビットパーフェクトミキサー設定、WASAPI排他出力、SMB、DTCP-IP、キャスト、音声デバイスの選択UI、ギャップレス保証、再生位置の永続復元は未実装。
