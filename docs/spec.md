# ContinuousPlayer Windows版仕様

現在のWindows版のコードとプロジェクト設定に基づく仕様。Android版の仕様・Kotlinコード・デザイン資産を移植元とし、Windows固有の画面・再生方式・保存処理を以下に定義する。

利用手順は[README](../README.md)、プロジェクトごとの責務は[内部構成](architecture.md)、ビルド・自己完結型発行は[開発環境とビルド方法](development.md)を参照する。

## 構成

| 対象 | 実装 |
|---|---|
| UI | WinUI 3 / Windows App SDK 2.5.1 / CommunityToolkit.Mvvm 8.4.2 |
| ターゲット | .NET 10、Windows SDK 26100、最低OS 17763（Windows 10 1809） |
| アーキテクチャ | x64 / ARM64 |
| 配布形態 | 単一プロジェクトMSIX、WinApp CLIによる開発登録 |
| 標準再生 | Windows.Media.Playback.MediaPlayer + MediaPlayerElement |
| 排他音声再生 | Media FoundationによるPCMデコード + WASAPI排他出力、NAudio.Wasapi 2.4.0 |
| 再生制御 | IPlaybackEngineを共通契約とし、PlaybackEngineSessionとPlaybackSessionStateで所有・状態を管理 |
| 永続化 | ApplicationData.Current.LocalFolder内のlibrary.jsonとaudio-settings.json |
| 共通処理 | ContinuousPlayer.Core（WinUIへの依存なし） |
| Windows音声処理 | ContinuousPlayer.Audio.Windows（デコード・排他出力・機器列挙） |

アプリとWindows音声処理のターゲットは`net10.0-windows10.0.26100.0`、Coreは`net10.0`。ReleaseはJIT / ReadyToRunを使用し、トリミングは無効。自己完結型の発行時は.NETとWindows App SDKの両方を同梱する。起動・保存先の取得にはパッケージIDを使用する。

## 画面と操作

ホームは濃紺グラデーション、重なる映像フレームと再生矢印のロゴ、英字ラベル、アプリ名、280×56 DIPの「動画フォルダーを選ぶ」を表示する。アプリ内の終了ボタンは置かずOSのウィンドウ操作を使う。小さいウィンドウではスクロールする。初期のページ領域は1024×576 DIP（16:9）とし、タイトルバーとウィンドウ枠を別に確保する。最小サイズは440×380 DIPを基準にモニターのDPIで調整する。

ブラウザーは最大880×800 DIP。同一のオーバーレイを維持し、戻る・キャンセル・フォルダー名・再読み込みを上部に配置する。ファイル行は20 DIPの名前と再生アイコン、フォルダー行には右矢印を表示する。NASのサーバー一覧にはアドレスを表示する。リストはListViewで仮想化する。ブラウザー外のクリックでは閉じない。

ファイル選択後は黒い再生画面を描画してからブラウザーを閉じる。開始・終了・ホーム遷移でウィンドウ／全画面状態を維持する。F11と画面ボタンで全画面を切り替える。通常時はタイトルバー、全画面では上端操作部内に切替ボタンを設ける。

ウィンドウ表示では、対応拡張子を除いたタイトル、状態文、ホームに戻る → ファイル一覧 → メディア情報 → 音声出力設定をタイトルバーに常時表示する。タイトルバーは高さ32 DIP、追加操作ボタンは32×28 DIP、アイコンは16×16 DIPを基準にする。長いタイトル・状態文は操作ボタンと重ならない幅で末尾を省略し、リサイズとファイル切り替えに追従する。ホームでもアプリ名と操作ボタンを表示し、再生中のメディアが必要な操作は無効にする。

全画面ではタイトル・状態文と上端の操作を動画上のオーバーレイに配置する。下端中央は前のファイル → 10秒戻す → 再生/一時停止 → 10秒進める → 次のファイルで、ウィンドウ表示でもオーバーレイに配置する。映像の位置・大きさを変えずに操作部を表示・非表示にする。音声のみの場合は中央にもタイトルとジャケットまたは音楽アイコンを表示する。元の名前はツールチップ・読み上げ名・メディア情報に保持する。

再生領域の矢印は←／→で前／次、↑／↓・Shift＋←／→で±10秒。操作部の矢印は上下両列のフォーカス移動、Space/Enterはそのボタンを実行する。Tab／Shift+Tabも利用できる。先頭の前・末尾の次は無効化し、CanSeek=falseなら±10秒を無効化する。

直接タッチは左右1/3のタップで±10秒、中央1/3で再生切り替え。横70 DIP以上・横距離が縦の1.5倍以上のスワイプで前後移動し、速度条件は設けない。ダブルタップは初回を即応し2回目を抑制する。複数指・取消・キャプチャ喪失は操作に変換しない。マウス/トラックパッド/ペンは背景の位置によらずクリックで再生切替、ドラッグで曲送りしない。非アクティブ時の最初のマウスクリックはフォーカス取得のみとする。OSのダブルクリック設定と標準メディアキーの押下/解放を使い、二重操作・長押しの連続操作を防ぐ。詳細は[入力の設計](common-spec-stage2-design.md)を参照。

一覧の左右とPage Up/Downは、仮想化されたListViewの可視項目数を基準に移動し、次の選択を表示する。最前面の一覧/情報/エラーと文字入力欄を再生コマンドより優先する。

Spaceによる一時停止・再開、一覧・情報画面の終了、ウィンドウへの復帰では、操作部をキーボードで選択中の場合を除き再生領域へフォーカスを戻す。タイトル文字・空白部分のクリックやウィンドウのドラッグ終了後も再生ショートカットを使える。F11・I・O・Hはタイトルバー側にフォーカスがある場合も受け付ける。

動画上・ブラウザーの操作ボタンは48 DIPを基本とし、タイトルバーには小型の操作ボタンを使う。AutomationId・読み上げ名・フォーカス表示を付ける。色はテーマ資源にまとめ、HighContrastではシステム色を使用する。

動画の再生開始・再開と再生キー操作では、動画上の操作部とカーソルを直ちに非表示にし、ファイル切り替え先の準備中も操作部を非表示に保つ。ウィンドウのタイトルバーは表示を維持する。動画上でマウスを動かすか押すと再表示し、3秒間停止すると非表示にする。ボタン上のホバー・マウス操作で残ったフォーカス・ウィンドウ外への移動・非アクティブ化だけでは操作部の非表示カウントを止めない。カーソルを隠すのはウィンドウがアクティブでポインターが再生領域上にある間だけとする。

操作部をキーボードで選択中、OSのスクリーンリーダーフラグが有効、一時停止、音声のみ、前面の一覧・ダイアログ、終了・失敗では操作部の表示を保つ。UIAクライアントのイベント購読だけではスクリーンリーダーと判定しない。バッファリングだけで再生意図や一時停止UIを切り替えない。ホーム・ブラウザーではカーソルを隠さず、終了時にタイマーとカーソル資源を解放する。

非表示には透明なInputCursorを使用し、入力用コントロールとContentIslandに設定する。実際のポインター座標を監視して待ち時間を管理する。キーボード再開後にシステム矢印が残る場合に備え、非表示への切り替え時に元の座標へ戻るポインター更新を送る。非アクティブ時、マウスボタン操作中、OSがポインターを非表示にしている場合は更新を送らない。

## フォルダーと再生

- ローカル・USBは標準フォルダーピッカーまたはドライブ一覧から追加する。追加中はフォルダーだけを閲覧し、「このフォルダーを登録」で保存済み一覧の登録行に戻る。登録だけでは再生しない。OSピッカーの取消は保存先選択へ、追加のキャンセル/Escは保存済み一覧へ戻る。
- 通常のローカル・DLNA閲覧は登録ルートを境界にし、その親は保存済み一覧へ戻る。子から親へは直前の子を、保存済み一覧へは登録行を選択する。最上位の親は選択全体の取消。取得中の親/取消は要求を中断して選択全体を閉じる。
- 一覧と再生タイトルは同じ表示名処理を使う。既知の末尾拡張子だけを省略し、同名衝突には形式バッジを表示する。原名とIDは保持し、最大2行の表示、ツールチップ、読み上げで識別できる。
- 読み取りは選択フォルダーの直下のみ。再帰スキャンは行わない。ローカルファイルを変更・削除しない。
- 一覧の対象拡張子は`.mp4 .m4v .mp3 .flac .m4a .aac .wav .ogg .opus`。`._`で始まるAppleDoubleファイルを除外する。OP/EDのグループ内位置だけの並べ替え、季節シリーズの年・冬春夏秋順の並べ替えを行う。実際にデコードできる形式はWindowsのコーデック構成に依存する。
- 選択インデックスから0秒で開始。末尾で「最後まで再生しました」と表示して停止し、自動リピートしない。明示再生では最終ファイルの0秒から再生する。前後移動は範囲内だけ行う。一時停止中の曲送りは停止状態を保持する。
- 巻き戻しは0秒で止める。既知の末尾を超える早送りは次があれば曲送り、なければ移動しない。CanSeekがfalseのソースはシークしない。
- 再生エラーは自動スキップせず、原名・原因別の接続/アクセス案内・最後の確認位置・詳細/HRESULTを表示する。再試行／次のファイル（次がある場合のみ）／ファイル一覧／閉じるを分ける。閉じるだけなら失敗を維持し、中央ボタンを「再試行」にする。
- 再試行は同じファイルIDを開き直し、準備後のシーク完了と実位置を確認してから再生する。復元確認の上限はローカル5秒、HTTP/HTTPS音源25秒。復元不可・上限内に確認不可なら案内して手動再開を待つ。準備中の割り込み後も自動再開しない。確認位置は実行中セッション内だけ保持し、別ファイルの準備失敗は0秒。旧メディアへ戻らず、自動再試行しない。
- 再生基盤が切断を通知しない場合も、再生意図のある準備/再生で位置が30秒変わらなければエラーを表示する。一覧・情報・利用者の停止・割り込み中は監視をリセットし、短いバッファリングでは停止扱いにしない。
- ホーム・ウィンドウ終了では再生エンジン・ソース・画面消灯抑止を解放する。一覧・情報の表示ではセッションとエンジンを保持する。排他音声の出力ストリームは一時停止時に解放する。ファイル切り替えでは旧エンジンの解放完了を待って新エンジンを準備し、旧エンジンの遅延通知を新しいファイルへ適用しない。
- 他アプリへの通常のフォーカス移動は再生を維持する。最小化・明示非表示・ロック・スリープ・利用中の音声出力機器切断・再生基盤からの割り込みでは一時停止し、復帰後は手動再開とする。複数の中断理由がある場合はすべて解除されるまで再開しない。
- Escapeとフォルダーボタンは一時停止して現在の再生元を開き、ファイルIDで選択位置を復元する。取消では元の位置と再生意図に戻り、表示中に割り込みがあれば停止を維持する。ファイル選択確定では同じファイルでも0秒から新規再生する。ホームは保持中のセッションも終了して初期画面へ戻る。
- 再生情報は一時停止して表示し、I・Esc・閉じるで情報だけ閉じ、一覧取消と同じ条件で復元する。一覧・情報・エラー表示中のメディアキーは背後へ伝えない。再生情報にはファイル名・サイズ・時間・再生位置・キュー位置・取得できた映像/音声形式を表示する。音声は設定モード、実際の再生モード、出力先、再生基盤を分けて表示する。排他では機器ID、デコードPCMと直近の初期化済み出力形式（レート・チャンネル・有効ビット数・格納幅）、排他解放状態を表示する。標準ではPCM形式をWindowsが管理する旨を示し、排他レートとして扱わない。物理デバイス名が取得できないときは「Windows既定の再生デバイス」と表示する。

## 音声出力

### モードと出力機器

歯車ボタンの「音声出力設定」から「標準」「曲に合わせる（排他）」と出力機器を選ぶ。ホーム・ウィンドウのタイトルバーと全画面の上端操作部から開ける。初期値は標準。標準再生はWindows既定出力を使用し、機器選択は排他モードに適用する。排他ではWindows既定機器または機器IDを指定した出力先を使う。

機器一覧は更新でき、保存した機器が不在でも選択を保持して「未接続」と表示する。設定の保存に失敗した場合はダイアログに案内し、変更を確定しない。

再生中にモードまたは機器IDを変更した場合は、同じファイルの確認済み位置を復元して一時停止し、手動再開を待つ。変更せず閉じた場合は元の再生意図へ復元するが、表示中に割り込みがあれば自動再開しない。設定は次回起動にも引き継ぐ。

### 標準再生と排他再生の選択

- 標準は動画・音声に`MediaPlayerPlaybackEngine`を使用する。
- 排他のローカル対象は`.wav .flac .m4a .mp3 .aac .ogg .opus`の音声ファイル。UNCパスは標準再生とする。
- NAS/DLNAのHTTP/HTTPS音声も排他対象とする。MIME、ファイル名・URLの拡張子から候補を判断し、受信データのストリームを調べる。
- 映像を含むファイル、動画MIME、排他対象外のファイルは標準再生とし、情報画面に理由を表示する。M4Aなどの拡張子だけで音声専用とは判断しない。
- 排他候補の機器・形式・デコード・配信条件に問題がある場合はエラーとし、自動で標準再生へ切り替えない。「この曲を標準再生」を明示的に選べる。この操作は当該曲だけをWindows既定出力の標準再生にし、保存した排他設定は変更しない。

### 排他出力の形式とライフサイクル

Media FoundationでデコードしたPCMのレート・チャンネル数を出力の基準にする。整数16/24/32-bit PCMを扱い、機器が受け付ける形式へ精度を保った格納幅の拡張を行う。無断のレート変換やビット幅の切り捨ては行わない。浮動小数点WAVの排他再生は未対応。

曲ごとに形式交渉とWASAPI排他ストリームの初期化を行う。自然終了は供給済みPCMの出力完了後に通知し、次曲へ進む。手動の曲送りでは残りを破棄する。一時停止・一覧/情報表示・最小化・ロック・スリープでは排他ストリームを解放し、再開時に現在位置からデコードと出力を再準備する。一時停止中のシーク・曲送りは停止状態を保つ。

選択機器の消失・無効化や、使用中のWindows既定出力の変更では停止し、手動再開を待つ。特定機器が利用できない場合に別機器へ自動出力しない。排他利用中は同じ機器を他アプリが利用できない場合がある。形式非対応・他アプリの占有・排他禁止・デコード非対応・通信エラーは原因に応じて案内する。

### HTTP音声

排他音声のHTTP読み取りはRangeと正しいContent-Range・全体サイズを必要とする。ストリームごとに1 MiB単位・最大8 MiBをキャッシュする。接続上限は5秒、各ブロックの要求・読み取り上限は10秒。サイズ、ETagまたはLast-Modifiedの変化を検出した場合は、異なるデータの混在を防ぐため停止する。

通信断・不完全な応答を自然終了と区別し、再試行では最新の配信URLを取得して確認済み位置を復元する。DLNAサーバーが変換済みリソースを返す場合はその旨を情報に表示し、元ファイルのタグではなく受信・デコードしたPCMのレートで出力する。

## 音楽のジャケット表示

音声のみの再生では、Windowsの音楽サムネイル（埋め込みジャケットなど）を優先する。取得できない場合は同じフォルダーから、曲名と同名、`cover`、`folder`、`front`、`album`の順にJPEG / PNG / WebPを探す。DLNAではサーバーが通知するHTTP/HTTPSのジャケットURLを使う。

画像は縦横比を保ち、ウィンドウサイズに合わせて縮小して中央に表示する。画像なし・取得失敗・破損画像では音楽アイコンを表示し、再生は継続する。画像取得は8秒・8 MiBを上限とし、曲切り替え・終了後の遅延応答を表示しない。

## 保存

保存先は`ApplicationData.Current.LocalFolder`。`library.json`に登録済みフォルダー、最後の登録先、再生元の階層、ファイルIDをVersion 1のJSONで保存する。同じキーの再登録は更新する。DLNAのキーはサーバーIDとフォルダーID、ローカルは大文字小文字を無視した絶対パス。ファイルへの書き込みを直列化し、一時ファイルから置き換える。壊れた保存データは起動時に案内し、登録の再作成が可能。プロセス終了後の再生位置・プレイリスト・実行中のブラウザー位置は復元しない。同じ実行中セッションの一覧・情報を閉じる際の位置復元は行う。

`audio-settings.json`には音声出力モード、機器ID・名称をVersion 1のJSONで独立して保存し、フォルダー登録の形式を変更しない。設定を読めない場合は案内して標準再生を使用し、元のファイルを保持する。音声設定の書き込みも直列化し、一時ファイルから置き換える。

保存済み行の登録解除はDelete・右クリック・長押しから同じ確認画面を開いて行い、専用の解除ボタンやポップアップメニューを置かない。解除後は次行、なければ前行、0件なら追加へフォーカスする。オフラインでも解除でき、実ファイルは削除しない。ファイル行の長押し・右クリックでは再生や情報を開始しない。

## DLNA

- SSDP M-SEARCHはIPv4マルチキャスト239.255.255.250:1900、4秒間、1.5秒間隔、最大32 LOCATION。デバイス記述はその後に順次取得する。UDNで重複を除く。
- ContentDirectoryのルートは0。SOAP BrowseDirectChildrenを200件単位で取得する。次ページはフィルター後の件数でなくNumberReturnedで進める。
- DIDL-Liteのcontainerとaudio/video HTTPリソースを扱う。汎用MIMEは拡張子で判定する。元データを変換済みリソースより優先する。
- 同じ項目の繰り返し、不完全なページ、10万件を超える一覧はエラー。XMLは4 MiBまで、DTDと外部エンティティは禁止。接続5秒、要求・読み取り8秒の上限を設定する。
- 探索中も「アドレスを指定して接続」へ移れる。ホスト名・IPv4・角括弧付きIPv6（ポート指定可）とHTTP/HTTPSの完全なデバイス記述URLを受け付ける。スキーム省略時HTTP、パス省略時 `/desc/device.xml`、その場合ポート省略時50001。完全URLのパス/クエリを保持し、内部空白・認証情報・フラグメント・不正ポート・パスなしクエリは拒否する。失敗時の入力を保持し、接続中も取消可能。探索/接続の遅延応答で入力や画面を戻さない。
- 登録時にサーバーID・名称、フォルダーのID階層、記述URLを保存する。Version 1の任意項目追加とし、旧登録も読める。不正な任意URLは空にして登録を保持する。記述URLがあれば直接、なければSSDPで再接続し、旧登録も成功時に記述URLを保存する。失敗時は「接続先を再指定」で同じサーバーIDを検証して変更できる。UDNがなくLOCATIONをIDにするサーバーでは、アドレス変更後の同一性を保証できず別登録として追加する。
- メディアURLは永続化せず、再生開始/次送り/再試行で同じIDを再取得する。既存キューの順序・件数は保持し、見つからない場合は明示的に失敗する。
- ローカル・ドライブ・DLNAの取得中は前の一覧と見出し・選択を維持する。古い行の決定・登録・再読み込みは無効にし、親/キャンセルは常時可能。0.5秒後に読み込み表示を重ねる。要求の世代を検査し、取消後の取得や標準ピッカーの完了で画面を戻さない。エラーでも登録は保持する。
- Windowsファイアウォールやネットワークのマルチキャスト設定に依存する。

## Android版との差分・未対応

AndroidのSAF・TV用権限・画面回転・メディアセッションはWindowsのピッカー・ドライブ・ウィンドウリサイズ・SMTCに置換する。Windowsの標準コーデックで再生するためExoPlayerとの完全な形式互換性は保証しない。

WASAPI排他音声出力と音声デバイス選択は実装済み。動画の音声は標準再生とする。Windows全体の共有ミキサー設定は変更せず、ビットパーフェクト・ギャップレスは保証しない。追加デコーダーは同梱せず、OGG/Vorbis・Opusなどの再生可否はWindowsのデコーダーに依存する。

SMB専用クライアント、NASへのログイン、DTCP-IP、キャスト、DSD/DoP、ASIO、Android TV固有API、再生位置・プレイリストの終了後復元、バックグラウンド再生サービスは対象外。

## 起動オプションと診断

通常起動は保存した音声出力設定を使う。`--exclusive-audio`で排他モード、`--standard-audio`で標準モードをセッション単位で上書きする。`--audio-device`は`--exclusive-audio`と組み合わせて機器IDを指定し、省略時はWindows既定出力を使う。標準と排他の同時指定は受け付けない。起動引数だけでは保存設定を書き換えない。

`--audio-log`で任意のJSONL診断ログの出力先を指定できる。ログには再生操作・中断・セッション状態・排他音声の形式などを記録する。未処理例外・起動例外はLocalFolderの`last-error.log`に記録する。
