# ContinuousPlayer for Windows

Android版の仕様・Kotlinコード・デザイン資産をもとにした、WinUI 3製の動画・音声連続再生アプリです。濃紺・シアン・紫のホーム画面、ファイルブラウザー、一時停止ツールバーをAndroid版に合わせています。

## 機能

- PC・USBのフォルダーを登録し、独自ブラウザーからファイルを選択
- 同一LAN上のNAS / DLNAサーバーをSSDPで探索し、公開フォルダーを閲覧・登録
- 選択したファイルから同じフォルダー直下を連続再生（末尾で終了、リピートなし）
- `作品 OP → ED → OP2 → ED2` の整列、季節フォルダーの年・冬春夏秋順
- タッチの左右・中央タップ、横スワイプ、キーボード、Windowsメディアキー
- 再生元フォルダーへの復帰、現在のファイルへのフォーカス復元、一覧取消時の位置・再生状態の復元
- フォルダー登録と最後の選択位置の保存、オフラインでの登録解除
- 再生エラーの表示・再試行、メディア情報、全画面再生

列挙する形式: `.mp4 .m4v .mp3 .flac .m4a .aac .wav .ogg .opus`。`._`で始まるAppleDoubleファイルは除外します。デコードできる形式はWindowsのコーデック構成にも依存します。

## ビルド・起動

Windows 10 1809以降 / Windows 11、.NET 10以上のSDK、WinApp CLI 0.7.1以上、開発者モードが必要です。現在の開発環境では.NET SDK 11 RCを利用し、アプリのターゲットは.NET 10です。通常のJITビルドにC++ツールチェーンは不要です。

```powershell
winget install --id Microsoft.WinAppCli --exact
dotnet build .\ContinuousPlayer.slnx -p:Platform=x64
winapp run .\ContinuousPlayer --detach
```

Visual Studioでは `ContinuousPlayer.slnx` を開き、x64またはARM64を選んでください。起動時に自動でフォルダーピッカーは開きません。「動画フォルダーを選ぶ」→「フォルダーを追加」→「このフォルダーを登録」と進み、保存済み一覧から登録先を開いてファイルを選びます。追加の取消は保存済み一覧へ、選択全体の取消は元の画面へ戻ります。登録解除は保存済み行のDelete、右クリック、長押しから確認して行います。実ファイルは削除しません。

## 操作

| キー / タッチ | 動作 |
|---|---|
| Space / Enter、中央タップ | 再生 / 一時停止 |
| ← / → | 前 / 次のファイル |
| ↑ / ↓ | 10秒巻き戻し / 早送り |
| Shift＋← / →（再生領域） | 10秒巻き戻し / 早送り |
| マウスで背景をクリック | 位置によらず再生 / 一時停止。ダブルクリックも切替1回 |
| 左 / 右1/3のタップ | 10秒巻き戻し / 早送り |
| 右 / 左スワイプ | 前 / 次のファイル |
| Esc / O | 一時停止して再生元フォルダーを表示。取消で元の位置・再生意図へ復元 |
| H | ホームへ戻る |
| I | 一時停止して再生情報。情報内のI / Escで閉じて元の状態へ復元 |
| F11 / 全画面ボタン | 全画面の切り替え |
| Tab / Shift+Tab | ボタン間の移動 |
| Enter（操作部内） | フォーカス中の操作 |
| 矢印（操作部内） | 操作ボタン間のフォーカス移動 |
| ← / →、Page Up / Down（一覧内） | 可視項目数を基準にページ移動。端で循環しない |
| F5（ブラウザー内） | 再読み込み |
| Backspace / Alt+←（ブラウザー内） | 親へ移動 |
| Esc（ブラウザー内） | キャンセル（取得中も可能） |

通常の一覧では登録ルートから上へ戻ると保存済み一覧を開き、子階層から戻ると直前の子を選択します。対応拡張子は表示だけ省略し、同名になる行には形式バッジを付けます。原名はツールチップ・読み上げ・メディア情報で確認できます。取得が0.5秒を超える場合は元の一覧に読み込み表示を重ね、取得中の親/取消で選択全体を取り消します。

再生開始・ホーム復帰でもウィンドウ／全画面の状態を維持します。上端にタイトルとホーム・ファイル一覧・メディア情報、下端に前・10秒戻す・再生/一時停止・10秒進める・次を表示します。他アプリへフォーカスを移しても再生を続けます。最小化・非表示・ロック・スリープ・利用中の音声出力機器の切断では一時停止し、復帰後は手動再開を待ちます。一覧・情報の表示中に割り込みがあった場合も、閉じる操作では自動再開しません。Windowsの音量キーはOSに任せます。

再生の矢印・Space・Enterは再生領域にフォーカスがある場合の割当です。ボタンにフォーカスがあればそのUIを優先し、文字入力や最前面のダイアログから背後の再生を操作しません。マウスのドラッグはファイル送りにせず、直接タッチだけを3分割タップ・横スワイプとして扱います。二重タップの2回目とキー長押しによる連続送りを抑制します。

動画再生中は、マウス操作が3秒間ないと操作部とカーソルを非表示にします。ボタンへのフォーカス・ポインター・読み上げ操作中は表示を保ちます。マウスを動かすかクリックすると再表示されます。一時停止中、情報表示中、音声のみの再生、ホーム・フォルダー画面では非表示にしません。

```powershell
dotnet run --project .\tests\ContinuousPlayer.Core.Tests
.\scripts\New-TestMedia.ps1  # UI検証用の無音WAVを生成

.\scripts\Test-MigrationReadiness.ps1 # 追跡ロックファイルを保持してビルド・Coreテスト
.\scripts\Test-Stage1.ps1   # 一覧・情報の復元、通知注入、最小化のローカルUI確認
.\scripts\Test-Stage1-ContinuousPlayback.ps1 # 自然終了の次送り・最終終了後の再生
.\scripts\Test-Stage2.ps1   # ページ移動、フォーカス、マウス/タッチ、キー長押し
.\scripts\Test-Stage3.ps1   # 上下操作部、全画面、サイズ変更、動画の表示制御
.\scripts\Test-Stage4.ps1   # 境界、追加・登録・解除、表示名、制御DLNAの遅延取消
# カーソル検証: 60秒以上の動画1本のみを置いた専用フォルダーと、起動中アプリのPIDを指定
.\scripts\Test-Cursor.ps1 -AppPid 1234 -VideoPath C:\TestVideo\sample.mp4
```

共通ロジックのテストは追加テストフレームワークなしで実行できます。整列・列挙・キュー境界・永続化・XML・ローカルHTTPサーバーによるSOAP/ページ分割を検証します。NAS実機での探索・再生と、物理タッチパネルでの確認は別途必要です。

共通仕様への移行状況は[改修計画](docs/common-spec-migration-plan.md)と[受入確認表](docs/common-spec-acceptance.md)に記録します。第1段階のUIスクリプトはPC全体をロック・スリープさせず、対象アプリへの通知注入で中断処理を確認します。実際のロック・スリープ・音声機器切断の実機確認とは区別してください。

## Windows版の範囲

再生にはWinUIの`MediaPlayerElement`とWindows `MediaPlayer`を使用します。AndroidのSAFはWindowsのフォルダーピッカーへ置き換えています。USBはOSにマウントされたドライブが対象です。AndroidのUSB Preferred Mixer Attributesに相当するビットパーフェクト設定、WASAPI排他出力、Android TV固有APIは実装していません。音声はWindows標準ミキサー経由です。再生位置・プレイリストのプロセス終了後の復元、バックグラウンド再生サービスも対象外です。

DLNAは公開されたContentDirectoryを読み取ります。NASのログイン、SMB、DTCP-IP、キャストには対応しません。保存にはサーバーIDとフォルダーIDを使い、再接続時にURLを取得し直します。

詳細は[Windows版仕様書](docs/spec.md)を参照してください。再生APIは[MicrosoftのMediaPlayer資料](https://learn.microsoft.com/en-us/windows/apps/develop/media-playback/play-audio-and-video-with-mediaplayer)に基づいています。
