# ContinuousPlayer for Windows

Android版の仕様・デザインをもとにした、WinUI 3製の動画・音声連続再生アプリです。Windows 10 1809以降 / Windows 11で、PC・USBやNAS / DLNAのメディアを再生できます。

## 機能

- PC・USBのフォルダーとNAS / DLNAの公開フォルダーを登録し、アプリ内のブラウザーから選択
- 選択したファイルから、同じフォルダー直下を連続再生（末尾で終了、リピートなし）
- `作品 OP → ED → OP2 → ED2`、季節フォルダーの年・冬春夏秋順での整列
- キーボード、マウス、タッチ、Windowsメディアキーによる操作と全画面再生
- 再生元フォルダー・選択位置への復帰、一覧や情報画面を閉じた際の再生状態の復元
- 音楽のジャケット表示、メディア情報、曲に合わせたWASAPI排他音声出力
- フォルダー登録と最後の選択位置の保存、オフラインでの登録解除
- 再生エラーの原因案内と、確認済み位置からの再試行

一覧に表示する形式は`.mp4 .m4v .mp3 .flac .m4a .aac .wav .ogg .opus`です。`._`で始まるAppleDoubleファイルは除外します。再生できる形式はWindowsのコーデック構成に依存します。追加デコーダーは同梱しておらず、検証環境ではOGG / Vorbis・Opusは未対応です。

## 使い方

### PC・USBのフォルダーから再生する

1. ホームの「動画フォルダーを選ぶ」を押します。
2. 「フォルダーを追加」から対象フォルダーを開き、「このフォルダーを登録」を押します。
3. 保存済み一覧から登録先を開き、再生したいファイルを選びます。

登録だけでは再生は始まりません。選んだファイルからフォルダー直下を順に再生し、子フォルダーは再帰的に読み込みません。USBはWindowsにマウントされたドライブが対象です。

追加の取消は保存済み一覧へ、選択全体の取消は元の画面へ戻ります。登録ルートから上へ戻ると保存済み一覧を開きます。登録解除は保存済み行のDelete、右クリック、長押しから確認して行います。実ファイルは削除しません。

### NAS / DLNAへ接続する

フォルダー追加時にNAS / DLNAを選び、探索されたサーバーの公開フォルダーを登録します。探索で見つからない場合は「アドレスを指定して接続」から、ホスト名・IPアドレス（ポート指定可）またはHTTP / HTTPSのデバイス記述URLを入力できます。

パスを省略すると`/desc/device.xml`を使い、その場合ポートも省略すると50001を使います。登録先に接続できなくなった場合は「接続先を再指定」から同じNASの新しいアドレスへ変更できます。NASのログイン、SMB、DTCP-IP、キャストには対応しません。

### 音声出力を設定する

歯車ボタンの「音声出力設定」で、出力モードと機器を選びます。設定は次回起動にも引き継がれます。

- **標準**（初期値）：Windowsの標準再生を使います。
- **曲に合わせる（排他）**：ローカルとNAS / DLNAの対応音声を、受信・デコードしたPCMのレートとチャンネル数に合わせて出力します。HTTP配信ではRangeと全体サイズを取得できるサーバーが必要です。動画・UNCは標準再生になります。

再生中に設定を変更すると、同じ位置で一時停止し、手動再開を待ちます。指定したDACが不在の場合は別機器へ自動出力しません。エラー画面で「この曲を標準再生」を選べます。ビットパーフェクトやギャップレス再生は保証しません。

### ジャケット・メディア情報を見る

音楽では埋め込みジャケットを表示します。ない場合は同じフォルダーの曲名と同名の画像、または`cover`・`folder`・`front`・`album`のJPEG / PNG / WebP画像を探します。DLNAではサーバーが通知する画像を使い、画像がない曲は音楽アイコンを表示します。

Iキーまたは情報ボタンで、ファイル名、再生位置、映像・音声形式、音声出力の情報を確認できます。一覧では対応拡張子を省略し、同名になる行には形式バッジを表示します。元の名前はツールチップ・読み上げ・メディア情報で確認できます。

## 操作

| キー / タッチ | 動作 |
|---|---|
| Space / Enter、中央タップ | 再生 / 一時停止 |
| ← / → | 前 / 次のファイル |
| ↑ / ↓、Shift＋← / → | 10秒巻き戻し / 早送り |
| マウスで背景をクリック | 再生 / 一時停止。ダブルクリックも切替1回 |
| 左 / 右1/3のタップ | 10秒巻き戻し / 早送り |
| 右 / 左スワイプ | 前 / 次のファイル |
| Esc / O | 一時停止して再生元フォルダーを表示。取消で元の位置・再生状態へ復元 |
| H | ホームへ戻る |
| I | 一時停止してメディア情報を表示。情報内のI / Escで閉じて元の状態へ復元 |
| F11 / 全画面ボタン | 全画面の切り替え |
| Tab / Shift+Tab | ボタン間の移動 |
| Enter（操作部内） | フォーカス中の操作 |
| 矢印（操作部内） | 操作ボタン間のフォーカス移動 |
| ← / →、Page Up / Down（一覧内） | 可視項目数を基準にページ移動。端で循環しない |
| F5（ブラウザー内） | 再読み込み |
| Backspace / Alt+←（ブラウザー内） | 親へ移動 |
| Esc（ブラウザー内） | キャンセル（取得中も可能） |

再生の矢印・Space・Enterは再生領域にフォーカスがある場合の操作です。操作ボタン、文字入力欄、最前面のダイアログを優先します。F11・I・O・Hはタイトルバーにフォーカスがあっても使えます。マウスのドラッグではファイル送りせず、直接タッチだけを3分割タップ・横スワイプとして扱います。

### 画面表示と一時停止

ウィンドウ表示ではタイトルとホーム・ファイル一覧・情報ボタンをタイトルバーに常時表示します。全画面では動画上端に重ねて表示します。下端には前・10秒戻す・再生 / 一時停止・10秒進める・次のボタンを表示します。再生開始やホーム復帰でもウィンドウ / 全画面の状態を維持します。

動画の再生開始・再開時やキー操作では、動画上の操作部とカーソルを非表示にします。マウスを動かすか押すと再表示し、3秒間停止すると非表示になります。一時停止、音声のみの再生、情報画面、操作部のキーボード選択中、スクリーンリーダーの利用中は表示を保ちます。

他アプリへフォーカスを移しても再生を続けます。最小化・非表示・ロック・スリープ・利用中の音声出力機器の切断では一時停止し、復帰後は手動再開を待ちます。一覧・情報画面の表示中にこれらが発生した場合も、閉じる操作では自動再開しません。Windowsの音量キーはOS側で動作します。

### 再生に失敗したとき

エラーでは自動で次へ進みません。「再試行」「次のファイル」（次がある場合）「ファイル一覧」「閉じる」を選べます。再試行は同じファイルの確認済み位置を復元してから再開し、復元できない場合はその旨を表示します。準備中に割り込みがあれば手動再開を待ちます。「閉じる」だけでは停止状態を保ちます。

フォルダー登録と最後の選択位置は保存しますが、アプリ終了後の再生位置・プレイリストの復元、バックグラウンド再生サービスは対象外です。
